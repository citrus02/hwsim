# 城堡线索场景文案 · 交接文档

> 这是一份**给文案 AI 的施工说明**。目标：为霍格沃茨模拟器里每一个可探索地点，写出"有真正存活感"的线索旁白与可调查选项，让玩家觉得这座城堡是活的、每个地方都不一样。
>
> 你只需要**产出符合规范的数据**（一段 JS 对象字面量）。底层逻辑、年级门控、随机化、回退兜底都已由工程侧写好，你不碰逻辑，只填内容。

---

## 1. 这是在做什么

玩家探索城堡时，世界系统会随机（或被传闻指引）在某地点触发一段"线索调查"：先弹出一段**旁白**（玩家到这儿看到/听到了什么），再给几个**选项**（玩家怎么应对），每个选项点开展示一段**结果文案**。

现状问题：除已写好的 14 个地点，其余地点共用同一套通用模板——"顺着声音找过去 / 观察周围的变化"，千篇一律，破坏代入感。

**你的任务**：为"待补清单"（第 7 节）里每个地点写专属旁白 + 选项，要求**每个地点各有特色**、**符合该地点氛围与正史**、**不出现当前学年不该有的剧情**。

---

## 2. 数据放在哪

全部写进 `npc-events.js` 顶部附近的常量 `PLACE_SCENES`（对象，键=地点名，值=该地点场景）。

| 常量 | 作用 | 你要动它吗 |
|---|---|---|
| `PLACE_SCENES` | 各地点专属场景（旁白+选项） | ✅ 往里加新地点键 |
| `GENERIC_SCENE` | 未写专属场景的地点的通用兜底池 | ❌ 不动 |
| `LOCATION_LEAD_INS` | 4 句轮换开场白，系统自动拼在旁白前 | ❌ 不动 |
| `INVESTIGABLE_PLACES` | 允许被传闻"点名"的地点名清单 | ⚠️ 见第 8 节 |

---

## 3. 数据结构规范（**严格按这个格式**）

```js
"地点名": {
  intro: [
    "字符串形式：任何年级都能出现的旁白。",
    "同一地点至少写 2 条，进同一地点会随机轮换，避免每次一样。",
    { text: "只在某些年级才合理的旁白。", minGrade: 2, maxGrade: 2 },
  ],
  choices: [
    { label: "选项按钮文字（4-8字）", result: "点选后的结果文案，一到两句，有画面、有信息、有后果暗示。" },
    { label: "第二个选项", result: "……" },
    { label: "第三个选项", result: "……" },
    { label: "只有某年级才出现的额外选项", result: "……", minGrade: 5 },
  ],
},
```

### 字段说明
- **`intro`**：数组，**每个地点至少 2 条**（建议 2–3）。条目可为：
  - 纯字符串 → 任何年级；
  - `{ text, minGrade?, maxGrade? }` → 受年级限制。
- **`choices`**：数组，**每个地点写 3 条**专属选项（可再加 1–2 条年级限定的额外选项）。每条：
  - `label`：按钮文字，4–8 个汉字，是一个**动作**（"贴到门缝往里看""追问他手里藏的东西"）。
  - `result`：结果文案，**1–3 句**，有画面、给一点新信息、暗示后续。
  - `minGrade` / `maxGrade`：可选，整数 1–7，见第 5 节。

### 关键约束（系统行为，必须知道）
1. **每个地点的 3 条基础选项都不要加年级限制**。系统按当前年级筛掉受限选项后，若该地点剩下**不足 2 条**，会整体退回通用池——你的特色就白写了。年级限定内容只作"额外第 4/5 条"。
2. `intro` 同理：保证至少 1–2 条**无限制**旁白。
3. 文案里**不要**写"【】"框、不要写选项编号、不要写"（点击）"。纯文本即可。
4. 可用 `\n` 换行，但一两句话通常不用。

---

## 4. 系统怎么用你的内容（背景）

- 旁白 = `开场白(系统随机1句) + 你的 intro(当前年级可用里随机1条)`。**开场白系统自动加，你别写"你来到XX"这种开头**，直接从"看到了什么"写起。
- 选项 = 你的 `choices`（当前年级可用的全部）。
- 玩家进同一地点多次会随机换旁白，所以 intro 写 2–3 条互不重复的画面最值。

---

## 5. 年级门控 ——「不要出现当前学年不该有的线索」

游戏 1991 年九月开学，玩家逐年升级。`minGrade`/`maxGrade` 按**玩家年级 1–7** 限定，系统用玩家当前年级自动过滤。

| 年级 | 学年 | 这一年才可以出现的主线线索 |
|---|---|---|
| 1 | 1991–1992 | 三楼走廊的三头犬·活板门·魔法石（**仅 1 年级**） |
| 2 | 1992–1993 | 密室被打开·蛇怪·石化·阿拉戈克在禁林（**主要仅 2 年级**） |
| 3 | 1993–1994 | 小天狼星·布莱克·摄魂怪·尖叫棚屋密道真相·卢平 |
| 4 | 1994–1995 | 三强争霸赛·火焰杯·圣诞舞会·穆迪（**仅 4 年级**） |
| 5 | 1995–1996 | 凤凰社·乌姆里奇·有求必应屋作 DA 训练场·D.A. |
| 6 | 1996–1997 | 混血王子的魔药课本·斯拉格霍恩·高级魔药 |
| 7 | 1997–1998 | 死亡圣器线（多在校外，校内从简） |

### 门控规则（务必遵守）
- **凡引用上表某条具体主线 → 必须加年级门控**：
  - 三头犬/活板门 → `maxGrade: 1`
  - 蛇怪/石化/密室被打开 → `minGrade: 2, maxGrade: 2`（其后蛇怪已被消灭，别再"听见蛇声"）
  - 小天狼星/摄魂怪/尖叫棚屋密道 → `minGrade: 3`
  - 火焰杯/三强争霸/圣诞舞会 → `minGrade: 4, maxGrade: 4`
  - 有求必应屋作 DA 总部/邓布利多军 → `minGrade: 5`
  - 混血王子课本 → `minGrade: 6`
- **纯氛围、不涉及主线时间点的内容 → 不要加门控**（"壁炉烧得很旺""猫头鹰焦躁""温室泥土味"），任何年级都成立，也是"至少 2 条无限制"的主力。
- **拿不准就写成通用氛围**，宁可不蹭主线，也不要"穿越"。一年级在大礼堂不该看到火焰杯。

### 已写地点需补门控（提醒）
`三楼走廊` 已写好，但三头犬/爪痕内容应只在 1 年级出现。请给它相关 intro/choices 补 `maxGrade: 1`，并为 2 年级及以后补几条"走廊已重新开放、只剩传说"的中性旁白/选项。

## 6. 文案质量要求 ——「真正存活感 / 每地点各有特色」

这是灵魂，逐条对照：

1. **地点必须一眼可认**。读旁白就知道是哪儿：黑湖有雾和触手、猫头鹰塔楼有羽毛和信、钟楼有齿轮和钟摆、地牢冷而潮、獾院飘点心香。**严禁"气氛不太对"这种放之四海皆准的**——那是通用池的活儿。
2. **写"人/活物在动"，不只写景**。有人压低声音、费尔奇巡逻、画像偷看、学生匆匆离开、海格藏东西。好场景里通常有"一个正在发生的小事件"。
3. **三个选项给三种人格**，避免同质：一条**深入探究**（凑近看/翻找/跟踪痕迹）、一条**与人物互动**（搭话/追问/安抚动物/问画像）、一条**克制谨慎**（记下就走/不打草惊蛇/赶在被发现前撤）。
4. **`result` 给"信息+后果钩子"**，别写"看了看没发现"。哪怕谨慎离开也留一句余味（"门后那声呼吸，已经牢牢钉进你今晚的梦里"）。
5. **语气**：第二人称"你"，简体中文，原著风味。可紧张、可幽默（海格、双胞胎）、可阴森（禁林、密室），**按地点调性走**。
6. **长度**：intro 每条 1–2 句；result 每条 1–3 句。宁短而精。
7. **正史人物**用通用译名（费尔奇、洛丽丝夫人、平斯夫人、海格、桃金娘、牙牙）。不确定该不该出现的具体人物（某年才来的教授）就用"一个高年级生""某位教授"代替。
8. **不剧透、不替玩家下结论**：线索是"看到的迹象"，把判断留给玩家。

## 8. 写完后的接线（每个新地点都要做）

每写好一个地点，把它的**地点名**加进 `INVESTIGABLE_PLACES` 数组（在 `npc-events.js`），传闻系统才会"点名"它、玩家才能被传闻指引追过去。

```js
const INVESTIGABLE_PLACES = [
  // …已有…
  "城堡储藏室", "霍格沃茨大礼堂", "格兰芬多公共休息室", /* 你新写的安全地点 */
];
```

> **例外**：危险/高年级限制地点（密室、八眼巨蛛巢穴、黑暗魔法聚集地、地牢囚室等）**先别加进** `INVESTIGABLE_PLACES`——它们本身需高年级才解锁，被传闻随机点名会让低年级看到"去不了的线索"。这些只写进 `PLACE_SCENES`（玩家主动探索到那里才触发）就够了。安全的日常地点（大礼堂、各休息室、储藏室、看台、温室、船坞等）才加进去。

## 10. 提交格式

交付**可直接粘贴进 `PLACE_SCENES` 的 JS 片段**，每地点一个键，外加一份"需加进 `INVESTIGABLE_PLACES` 的地点名清单"：

```js
// 追加到 PLACE_SCENES：
"城堡储藏室": { intro: [ … ], choices: [ … ] },
"霍格沃茨大礼堂": { intro: [ … ], choices: [ … ] },
// …

// 追加到 INVESTIGABLE_PLACES（仅安全日常地点）：
"城堡储藏室", "霍格沃茨大礼堂", …
```

## 11. 验收清单（自检）

- [ ] 每个地点 `intro` ≥ 2 条，其中 ≥ 1 条无年级限制。
- [ ] 每个地点 3 条基础 `choices` 全部无年级限制；年级限定内容只作额外选项。
- [ ] 三条基础选项覆盖"探究 / 互动 / 克制"三种取向，不雷同。
- [ ] 旁白一眼能认出是哪个地点，写出了"正在发生的小事件"。
- [ ] 每条 `result` 都给了"信息 + 后果余味"，没有"什么都没发现"。
- [ ] 所有引用主线剧情的内容都加了正确的 `minGrade`/`maxGrade`（对照第 5 节）。
- [ ] 没有出现当前学年不该有的人物/事件。
- [ ] 标点为中文全角，引号用 “ ”，无 markdown、无编号、无【】框。
- [ ] 安全日常地点已加入 `INVESTIGABLE_PLACES`；危险/高年级限制地点未加入。
