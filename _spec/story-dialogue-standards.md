# 剧情对白格式标准

用于 `story-events.js` 等剧情数据中的 `scene.text` 字段。目标是让剧情弹窗像麻瓜学术系文本一样清楚：旁白有节奏，人物信息有重点，对白和动作不混在一行里。

## 核心原则

- 一个弹窗只表达一个镜头或一个小节奏点。
- 旁白、观察、动作、对白必须分层，不要把重要信息塞进一整段长句。
- 段落之间使用一个空行，也就是字符串里写 `\n\n`。
- 普通中文句子可以写完整，渲染器会参考麻瓜学术系规则，在 `。！？` 后自动短行。
- 单个弹窗建议控制在 3-6 个短段落。信息很多时，拆成下一幕。

## 文本类型

### 旁白段落

用于交代环境、时间、情绪、简单动作。

```text
大礼堂千支蜡烛悬浮在半空，四张长桌上方飘动着学院旗帜。

新生们排成一列走进来，领头的女教授神情严肃，绿色长袍笔挺。
```

### 角色对白

角色名必须独立成行，格式为 `角色名：`。下一行写对白。

```text
麦格教授：
「我是麦格教授。」
```

渲染效果：

- 角色名显示为独立标签。
- 对白缩进显示。
- `「对白」` 会高亮。

### 动作段落

动作不要混进对白句子里，单独成段。

```text
她推了推方形眼镜。

麦格教授：
「分院仪式马上开始。」
```

不要写成：

```text
「我是麦格教授，」她推了推方形眼镜，「分院仪式马上开始。」
```

### 观察清单

当文本里出现人物、线索、物品、状态、任务目标等需要玩家注意的信息时，使用观察清单。每行以 `- ` 开头。

```text
你注意到其中三个人格外引人注目：

- 一个黑发瘦小的男孩，站在人群里显得有些局促。
- 一个红头发的男孩，不停地朝长桌方向张望。
- 一个头发蓬松的女孩，努力站得笔直，像是已经把所有规则都背熟了。
```

渲染效果：

- 清单会显示为重点信息块。
- 不会被当成普通旁白挤在一段里。
- 适合替代“其中三个人格外引人注目：一个……一个……和一个……”这种长句。

## 场景模板

### 环境 + 角色对白

```text
大礼堂千支蜡烛悬浮在半空，四张长桌上方飘动着学院旗帜。

新生们排成一列走进来，领头的女教授神情严肃，绿色长袍笔挺。

麦格教授：
「我是麦格教授。」

她推了推方形眼镜。

麦格教授：
「分院仪式马上开始。」
```

### 人物观察

```text
新生们紧张地排成一排。

你注意到其中三个人格外引人注目：

- 一个黑发瘦小的男孩，站在人群里显得有些局促。
- 一个红头发的男孩，不停地朝长桌方向张望。
- 一个头发蓬松的女孩，努力站得笔直。
```

### 点名 + 反应

```text
麦格教授：
「哈利·波特！」

这个名字一出口，整个大礼堂爆发出窃窃私语。

那个黑发男孩紧张地走上前，分院帽盖住了他的眼睛。

漫长的沉默之后——
```

### 多角色连贯对白

```text
格兰芬多长桌爆发出欢呼！

韦斯莱双胞胎：
「我们有波特了！我们有波特了！」

斯莱特林那边一片死寂。

一个金发男孩甚至摔了杯子。
```

## 数据写法

在 `story-events.js` 里，标准格式直接写进 `text` 字段。换行用 `\n\n`。

```js
{
  speaker: "旁白",
  text: "新生们紧张地排成一排。\n\n你注意到其中三个人格外引人注目：\n\n- 一个黑发瘦小的男孩，站在人群里显得有些局促。\n- 一个红头发的男孩，不停地朝长桌方向张望。\n- 一个头发蓬松的女孩，努力站得笔直。",
  choices: null
}
```

## 必须避免

- 避免把旁白、对白、动作写在同一行。
- 避免用破折号强行串联多个动作和对白。
- 避免让角色对白藏在旁白句子中间。
- 避免用英文引号 `"..."` 表示中文对白。
- 避免把三项以上的人物、线索、物品写成逗号长句；应改用观察清单。

## 不推荐示例

```text
大礼堂千支蜡烛悬浮在半空，四张长桌上方飘动着学院旗帜。新生们排成一列走进来，领头的女教授神情严肃，绿色长袍笔挺——「我是麦格教授，」她推了推方形眼镜，「分院仪式马上开始。」
```

```text
新生们紧张地排成一排。你注意到其中三个人格外引人注目：一个黑发瘦小的男孩、一个红头发的男孩、和一个头发蓬松的女孩。
```
