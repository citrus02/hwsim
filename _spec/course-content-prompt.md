## 世界观约束

- 游戏时间：**1991 年**，玩家是霍格沃茨一年级新生
- 视角：**研究麻瓜学术的巫师**——认为麻瓜知识有独立价值，态度是真正的学术好奇，不是猎奇或俯视
- 知识内容必须**准确**，学生读完真的能学到东西
- 年级阶段对应英国课程标准：KS3（1–3年级）/ GCSE（4–5年级）/ A-Level（6–7年级）

## 举例原则

**可以用：**
- 魔法世界通用设定（魔药、魁地奇、对角巷、霍格沃茨建筑、咒语机制、魔法生物）
- 模糊化主体："某位变形术学生"、"一次草药课实验"、"巫师社会中普遍的现象"
- 麻瓜知识与魔法的真实交叉点（化学↔魔药、物理↔飞行、生物↔神奇动物、拉丁语↔咒语词源）

**不能用：**
- 原著具体情节或点名引用主要角色的经历
- 上帝视角（破坏代入感）
- 1991 年后才发生的事件

## 输出格式

### 课程正文（lesson 文件内容）

```
【第 X 课：课程标题】

导入（1–2 句）
用魔法世界现象引出本节麻瓜概念，符合该教授的开场风格。

正文（2–4 段）
每段一个知识点，知识准确，可穿插 1 个巫师视角例子。
语气和措辞贴合教授人设。

本课要点
· 要点一
· 要点二
· 要点三（至多三条）

[联动提示：与 XX 魔法课相关——一句话，有自然联动时才写]
```

### 题库（questionBank 文件内容）

每课配 3–5 道题，格式：

```js
{
  lesson: X,
  questions: [
    {
      type: 'choice',          // 目前只用 choice
      difficulty: 1|2|3,       // 1=基础 2=理解 3=应用
      text: '题目文字',
      options: ['A. ...', 'B. ...', 'C. ...', 'D. ...'],
      answer: 'A',             // 正确选项字母
      knowledgePoint: '对应知识点名称',
      analysis: '解析，说明为什么这个答案是对的'
    }
  ]
}
```

题目中的情境可以用魔法世界背景包装，但考查的是真实学科知识。
难度分布建议：基础题 2 道，理解题 2 道，应用题 1 道。
