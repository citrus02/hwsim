# 线索场景文案手写标准

本标准用于 `npc-place-scenes-authored.js` 及后续拆分文件。拆分只为维护和审校，不允许用程序模板、正则拼接、同义替换或批量生成冒充手写内容。

## 基本交付单位

每个地点、每个年级至少 30 条 `encounters`。

每条 `encounter` 必须包含：

- `minGrade` / `maxGrade`
- 一段独立 `intro`
- 3 个独立 `choices`
- 每个 choice 有短动作 `label` 和对应 `result`

`intro` 与 `choices` 必须是同一件小事的三个处理角度，不能随机错配。

## 质量要求

1. 每条都要像玩家真的在霍格沃茨某个地点停留了一小会儿，而不是“发现线索模板”。
2. 地点识别必须强：不看 key 也能知道在哪里。
3. 一年级内容以新生视角、课堂之外的校园生活、初入城堡的陌生感为主。
4. 原著风格优先：画像、盔甲、费尔奇、洛丽丝夫人、平斯夫人、庞弗雷夫人、海格、皮皮鬼、长桌、楼梯、魔法物件都应自然出现。
5. 不要过早剧透后续年级主线；需要主线元素时必须严格年级门控。
6. 不要刻板化四院：格兰芬多不只有鲁莽，斯莱特林不只有阴谋，拉文克劳不只有谜题，赫奇帕奇不只有点心和善良。
7. 不要同质化：同一地点 30 条里不能反复使用“纸条、脚印、划痕、有人低声说话”作为唯一推进方式。
8. 少替玩家下结论，少用“显然、说明、不是普通、这意味着”。优先写可观察的画面、动作、气味、声音和反应。
9. 每条 result 要有信息、余味或后果钩子，不能写“什么也没发现”。
10. 选项要覆盖三类倾向：深入查看、与人/物互动、谨慎处理或离开。

## 可读密度标准

数量达标不等于文案达标。后续年级尤其不能因为主线更沉重，就把每条写成一句功能性反馈。

每条 `encounter` 必须让玩家读到一个完整的小停留：

- `intro` 原则上不少于 55 个汉字；如果更短，必须有非常明确的画面、人物动作或地点机制，不能只是“某处很安静”。
- 每个 `result` 原则上不少于 45 个汉字；更短时必须补足“动作后的变化 / 周围反应 / 余味钩子”三者至少其一。
- 一个选择点下去后，玩家要感觉自己刚刚在地点里做了一件事，而不是只读到一句判定。
- 三个 `choices` 的结果不能都收束到同一种句式：例如不能连续都是“你记下了这件事”“你没有追问”“你离开了”。
- 高年级内容可以更压抑、更克制，但不能更单薄。六、七年级的战争阴影必须落在具体生活细节里：家信、空座位、药瓶、巡逻脚步、被藏起的面包、教授没说出口的保护，而不是反复写“大家压低声音”。
- 不允许为了扩写而灌水。补长必须补在可观察细节、人情味、地点机制或后果上。

## 地点气质分离标准

每个地点必须先确定“地点气质”，再开始写 30 条。不能把同一套“纸条、脚印、低语、划痕、异响”换个地点名重复使用。

写作前为每个地点至少明确以下 4 项：

- 核心生活节奏：这里的人通常在做什么，是用餐、赶课、自习、休息、练习、养护植物、传信、值守，还是冒险边界？
- 核心感官：这里最先进入玩家感知的是什么，是蜡烛和食物香、潮湿冷风、粉笔灰、药水味、羽毛、钟声、草叶、湖水、壁炉火，还是画像说话声？
- 核心事件类型：这里适合发生哪类小事，是学生社交、校规摩擦、物件失控、动物互动、课堂余波、家信与想家、传闻发酵，还是危险边缘的试探？
- 禁用偷懒母题：这个地点最容易被写烂的重复元素是什么，写作时必须主动避开连续复用。

地点之间必须有可读差异：

- 大礼堂：学校心脏。重点是长桌、餐具、浮空蜡烛、天花板天气、学院沙漏、猫头鹰邮差、级长秩序、用餐礼仪、传闻如何在桌边发酵。不要只写“有人低声议论”。
- 黑湖湖畔：城堡边界。重点是水面、船坞记忆、潮气、芦苇、水鸟、巨乌贼的远距离存在、湖岸安全距离、独处与想家。不要每条都写“水下有黑影”。
- 庭院草坪：课间呼吸。重点是晒太阳、赶作业、练习小咒、学生社交、草叶与风、门廊公告、课间铃声、轻微失控的日常魔法。不要把它写成又一个走廊或又一个禁林前哨。
- 图书馆：克制、秩序和知识压力。重点是平斯夫人、书架、借阅记录、压低声音、学习焦虑、书本自己的脾气。不要把所有线索都写成“禁书区阴谋”。
- 走廊：流动和偶遇。重点是画像、盔甲、楼梯、脚步、费尔奇巡逻、迷路新生、换课拥堵。不同楼层要有不同功能，不要所有走廊都只是“可疑脚印”。
- 门厅：进出城堡的阈值。重点是大门回声、湿鞋和泥点、学院沙漏、来往人潮、外面天气进入城堡的一瞬间。不要写成大礼堂前厅的重复版本。

一组 30 条内部也必须有结构性变化，建议至少覆盖：

- 8 条学生日常：迟到、找座位、赶作业、练咒、想家、遗失物、朋友间的小尴尬。
- 6 条活物/物件互动：猫头鹰、蟾蜍、画像、盔甲、餐具、书本、植物、幽灵或半自动魔法物件。
- 6 条地点机制：天花板、沙漏、楼梯、钟声、湖水、温室照料规则、图书馆禁声规则等。
- 5 条季节/时间变化：清晨、午后、黄昏、雨天、初雪、宵禁前后。
- 5 条轻线索/余味：给玩家一点“这里还有故事”的感觉，但不抢主线、不提前剧透。

如果某一地点连续 3 条都可以把地点名换成别处而几乎不改正文，就判定为同质化，需要重写。

## 真实霍格沃茨感标准

“真实的霍格沃茨”不是每条都放大事件，而是让学校像每天都在自行运转。

必须体现：

- 学校生活的连续性：学生会反复经过、同一地点有早中晚不同状态、昨天的小麻烦会留下今天的小后果。
- 魔法的日常化：魔法不只制造危险，也会体现在会躲墨水的面包篮、提醒人的火把、过分有礼貌的餐具、会抱怨的画像里。
- 新生视角的陌生感：一年级不知道一切规则，会试探、误会、紧张，也会被高年级、级长、教授或地点本身温和纠正。
- 人情味和幽默：小尴尬、小善意、小失误、小照顾，比空泛的宏大阴谋更能让地点活起来。
- 克制的神秘感：线索可以让玩家记住一个疑点，但不要每条都宣布“这里有大秘密”。

避免以下写法：

- 把所有地点都写成侦探案发现场。
- 把所有选择都写成“查看 / 询问 / 离开”的同义替换。
- 把所有结果都写成“你发现这不是普通东西”。
- 为了显得魔法而滥用危险、尖叫、黑影、低语。
- 为了显得原著而堆名词；画像、幽灵、教授和地点机制必须服务于当前小事件。

## 审校清单

- [ ] 当前地点当前年级 `encounters >= 30`
- [ ] 每条 `choices.length === 3`
- [ ] 旁白和选项是同一事件
- [ ] 没有模板化句式连续复用
- [ ] 当前地点有明确地点气质，不能把 key 换掉后仍成立
- [ ] 30 条内部覆盖日常、活物/物件、地点机制、时间变化、轻线索
- [ ] 没有连续复用同一偷懒母题，如纸条、脚印、低语、划痕、黑影
- [ ] 没有后续年级穿帮
- [ ] 没有刻板学院描写
- [ ] 能读出“活着的霍格沃茨”
- [ ] 有新生视角、日常魔法、人情味和克制神秘感
- [ ] 通过 `node --check`
- [ ] 通过 encounter 数量校验
